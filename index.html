Policy Acknowledgement Tracker for Confluence

Turn Confluence pages into tracked policies. Employees confirm "read & understood" on the page itself; every acknowledgement is pinned to the exact page version — with recurring re-attestation campaigns and one-click audit evidence for ISO 27001, SOC 2, and QMS reviews.

Runs on Atlassian — zero egress Confluence Cloud Free ≤ 10 users

Getting started

  1. Install Policy Acknowledgement Tracker from the Atlassian Marketplace.
  2. In Confluence, open Apps → Policy Acknowledgements.
  3. Go to the Policies tab and click Track a policy page.
  4. Search for the page, assign Confluence groups or individual users, set a deadline, and (optionally) a re-attestation cycle. Click Start tracking.

Assignees now see an "Acknowledgement required" item in the page byline (under the page title) with a one-click "I have read and understood this page" button.

Features

📄 One-click acknowledgement on the page

Readers confirm right in the page byline — no separate portal. Each confirmation records the user, an exact timestamp, and the precise page version, so nobody attests to a document they haven't seen.

🔁 Recurring re-attestation campaigns

Set quarterly, semi-annual, or annual cycles per policy. When a new cycle starts, acknowledgements automatically re-open — the recurring policy-review control that ISO 27001 (A.5.1), SOC 2, and QMS auditors ask for. Each cycle is labelled (e.g. Q3 2026) in the dashboard and the evidence export.

🔄 Version-aware re-acknowledgement

When someone publishes a new version of a tracked page, pending status resets automatically (you can turn this off per policy). Acknowledgements always state which version was confirmed.

📊 Compliance dashboard

Per-policy completion bars, per-user status matrix (acknowledged / pending / overdue), deadlines, and cycle labels — one place to see who still owes you a confirmation.

📥 Auditor-ready evidence export

Export a CSV with user, page, version acknowledged, timestamp, deadline, and campaign cycle. The full acknowledgement history is immutable — removing a policy never deletes past evidence.

🙋 "My acknowledgements" inbox

Every user gets a personal view of pending and completed acknowledgements in Apps → Policy Acknowledgements.

How assignment works

  • Assign a policy to Confluence groups (membership is re-synced daily) and/or individual users.
  • The deadline is measured in days from when tracking starts (or from each cycle start for recurring campaigns). After that, outstanding users show as Overdue.
  • Only Confluence admins see the Dashboard, Policies, and Audit export tabs. Regular users see their own acknowledgements only.

Security & data residency

  • Built 100% on Atlassian Forge. All data is stored in Forge storage inside Atlassian's infrastructure — nothing ever leaves Atlassian. No external servers, no third-party subprocessors, no egress.
  • The app never reads your page content. It stores only page IDs, titles, version numbers, assignee account IDs, and acknowledgement timestamps.
  • Page reads and searches happen with the requesting user's permissions — the app cannot show anyone a page they couldn't already see, and it works even under strict app-access data security policies.

FAQ

Does it send email reminders?

Not in v1 — by design. Sending email would require data egress and would forfeit the Runs on Atlassian guarantee. Assignees see pending items in the page byline and their My Acknowledgements inbox. Opt-in notifications are on the roadmap.

What happens when I edit a tracked page?

If "require re-acknowledgement on new versions" is on, publishing a new version re-opens acknowledgements for everyone. The dashboard shows which version each person confirmed.

What counts toward billing?

Standard Atlassian Marketplace per-user pricing based on your Confluence user tier. Free for sites up to 10 users.

Can I delete acknowledgement history?

Removing a policy stops tracking but keeps history for audit evidence. Uninstalling the app permanently deletes all app data stored by Atlassian for the installation.
